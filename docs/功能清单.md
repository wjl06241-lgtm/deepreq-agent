# 需求助手功能清单

整理日期：2026-09-18。代码版本：package.json 标注 2.1.3。

本清单以当前工作区的实际代码为准，覆盖用户功能、管理后台、数据处理、运维脚本和对外接口。当前工作区包含未提交修改，因此不等同于某个已发布版本。

“已实现”表示存在实现代码，不表示本次已完成线上验证。本次为静态阅读，未启动服务、调用模型或连接生产数据库。标注“条件”的功能需要相应后端、权限、配置或依赖；标注“脚本”的功能需要人工运行，不是页面或机器人菜单功能。

| 内容 | 实际边界 |

| 流式逐字回复 | 当前在模型完成后发送最终卡片，可另有进度提醒；README 的流式表述不代表当前实现 |

| 通用知识库搜索 | 当前为文件名过滤及按需阅读，没有向量检索或语义搜索实现 |

完整功能范围应结合上表的条件和限制使用。README、旧部署说明及资料模板中与代码不一致的内容，应以本清单引用的实际实现为准。
