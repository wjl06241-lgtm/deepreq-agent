# 项目资料目录

把每个项目的**提示词**和**项目文档**按项目名放在这里，服务会自动生效（每次回答都会重新读取，**改完即生效，无需重启**）。

## 目录结构

\`\`\`
项目资料/
└─ <项目名>/                 ← 与飞书里 /project new <名称> 的名字一致
    ├─ 提示词.md             ← 本项目专属提示词（可选；存在则覆盖全局提示词）
    ├─ 项目文档.md           ← 项目背景/需求文档/术语/决策记录
    └─ 其他 .md/.txt 文件     ← 也都会自动注入（按文件名排序，合计约 30KB 上限）
\`\`\`

## 规则

1. **提示词优先级**：项目资料/<项目名>/提示词.md ＞ config.json 的项目 prompt ＞ config.json 全局 systemPrompt。
2. **文档注入**：目录下所有 .md/.txt（除 提示词.md）自动追加进本项目对话的系统提示词，合计上限约 30KB，超出按文件名顺序截断。
3. **文件编码**：保存为 **UTF-8**（记事本另存为时选 UTF-8，不要用 ANSI）。
4. 其他格式（docx / pdf / xlsx）：先转成文本或 md 再放入。
5. 在飞书里执行 /project new <项目名> 时，会自动生成该目录及两个模板文件。

## 示例

\`\`\`
项目资料/
└─ 预约挂号/
    ├─ 提示词.md        ← 「你是预约挂号项目的需求分析师，术语：号源=…，重点关注 HIS 对接…」
    ├─ 项目文档.md       ← 项目背景、一期范围、验收标准
    └─ 历史需求结论.md   ← 之前几轮评审的结论
\`\`\`
