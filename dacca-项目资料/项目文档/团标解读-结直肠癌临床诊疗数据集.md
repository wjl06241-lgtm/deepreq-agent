## 1. 团标性质与定位

- 标准号 **T/SHIA 016—2025**，团体标准，按 GB/T 1.1-2020 起草。
- 由**四川大学华西医院**与四川省卫生健康信息中心共同提出，华西结直肠外科三十余年数据库经验为基础。
- 适用范围：指导结直肠癌诊疗信息的**采集、存储、共享、专科科研以及信息系统开发**。
- 大量引用国标/卫生行业标准（GB/T 2260 行政区划、WS/T 363 数据元目录、ICD-9/10/O-3 等），与国家级标准体系对齐。

> 关键判断：这份团标本身就是为"多机构、多场景、可共享"设计的——与本项目"多中心 + 多研究口径"的目标天然契合。它是 DACCA 本体建模的**字段级权威依据**。

## 2. 数据集整体结构

数据元采用规范的"公用属性 + 专用属性"描述：
- **公用属性**（表2）：版本、注册机构、相关环境、分类模式、主管机构、注册状态、提交机构。
- **专用属性**（表3-14）：内部标识符（HDSC50.xx.xxx）、数据元标识符（DExx.xx.xxx）、名称、定义、数据类型、表示格式、允许值（多数挂接值域代码表）。

## 3. 与本项目的对接判断（初步）

1. **天然多中心、多场景**：团标定位即"采集/存储/共享/科研"，与项目"多中心 + 满足尽可能多研究口径"完全同向。可直接作为本体的字段级基线。
2. **已是规范的数据元模型**：字段有唯一标识、定义、类型、值域，已具备本体建模所需的语义要素，不必从零定义。
3. **以患者为中心、可纵向追踪**：模块顺序天然贴合诊疗时间线（基本信息→病史→新辅助→术前→手术→术后→肿瘤评估→辅助→随访），与"可纵向追踪"目标一致。
4. **生存分析要素齐备**：随访模块含确诊日期、随访终期、生存状态、转移复发日期/类型 —— OS/DFS 等终点可直接由标准字段推导，支撑医药 RWS 与科研口径。

---

## 4. 待与用户确认 / 下一步（字段扩充方向）

- 团标约 320+ 数据元覆盖临床诊疗全流程，但面向"医药 RWS / 分子基因 / 卫生经济"三类口径，可能需扩充的方向（待确认）：
  1. **分子/基因**：KRAS/NRAS/BRAF/MSI/MMR 等标志物的检测方法、结果、检测日期是否足够细化（需核对 6.2.10 肿瘤评估模块明细）。
  2. **药企 RWS**：用药的通用名/批次/剂量/疗程/线数、不良事件（AE/SAE）等真实世界证据要素是否齐备。
  3. **卫生经济**：费用模块（6.2.4）的颗粒度是否支撑成本-效果分析。
  4. **院外/患者管理**：随访模块偏临床事件，院外画像（生活质量、PRO 量表、可穿戴等）需评估是否新增。
- **下一步**：逐模块核对字段明细，针对三类口径产出《团标字段扩充建议》。
